## Project Overview

Sweet Crumbs Bakery is a fictional South African bakery established in 2021. This website was developed as part of a web development project.

The website provides customers with information about the bakery, its products, business locations and contact details. It also allows visitors to search for products, submit order enquiries and prepare contact messages.
https://sweet-crumbs-bakery-odi.netlify.app

## Website Goals and Objectives

The main goals of the website are to:

- Provide the bakery with an online presence.
- Display the bakery's products.
- Provide information about the organisation.
- Allow customers to submit product enquiries.
- Provide contact information and business locations.
- Make important information easy to find through clear navigation.
- Improve the website's accessibility and search engine visibility.

## Forms and JavaScript Validation

### Order Enquiry Form

The enquiry form collects:

- Customer name.
- Email address.
- Phone number.
- Product selection.
- Required date.
- Quantity.
- Additional order requirements.

HTML5 validation and JavaScript are used to check the submitted information and display a confirmation message.

### Contact Form

The contact form collects:

- Customer name.
- Email address.
- Message type.
- Message content.

JavaScript validates the information and prepares an email using the visitor's default email application.(oth the order enquiry and contact forms use HTML5 and JavaScript validation. Form submissions are handled through Netlify Forms using AJAX. Successful submissions display a confirmation message)
